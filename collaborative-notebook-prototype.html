What is Recursion?

Recursion is a programming technique where a function calls itself to solve a problem. Instead of using loops to repeat operations, recursive functions break down complex problems into smaller, similar subproblems. Each recursive call works on a smaller piece of the original problem until reaching a simple case that can be solved directly.

The Base Case

Every recursive function needs a base case - a condition where the function stops calling itself and returns a direct result. Without a base case, the function would call itself infinitely, eventually causing a stack overflow error. The base case is like the "exit door" of your recursion - it tells the function when to stop.

📢 Teaching Moment from Dr. Smith

I've noticed many of you found base cases unclear. Here's a simple way to think about it: the base case is the answer you already know. For factorial, you know that 1! = 1. For Fibonacci, you know F(0) = 0 and F(1) = 1. Start with what you know, and recursion handles the rest!

The Recursive Case

The recursive case is where the function calls itself with a modified input, moving closer to the base case. Each recursive call should make progress toward the base case - if you're counting down, decrease the number; if you're processing a list, work with a smaller portion. This progress is essential to prevent infinite recursion.

Example: Factorial Function

Let's look at computing factorial (n!). The factorial of 5 is 5 × 4 × 3 × 2 × 1 = 120. Recursively, we can express this as: factorial(n) = n × factorial(n-1), with the base case factorial(1) = 1. Each call multiplies the current number by the factorial of one less, until we reach 1.

function factorial(n) {
    if (n <= 1) return 1;      // Base case
    return n * factorial(n-1); // Recursive case
}
